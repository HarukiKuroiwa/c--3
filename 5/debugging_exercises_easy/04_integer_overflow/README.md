# 04 階乗の計算

## このプログラムがやりたいこと
10! から 15! までを計算して表示する。

## 期待される出力
```
10! = 3628800
11! = 39916800
12! = 479001600
13! = 6227020800
14! = 87178291200
15! = 1307674368000
```

## 症状
`make run` で実行すると、12! までは正しいが、13! 以降の値がおかしい。

## 課題
1. `make run` で症状を確認し、**何番目から** おかしくなるかを確かめる
2. **なぜその番号から** おかしくなるのかを説明できるようにする
3. `problem.c` を修正し、`make check` が **PASS** になれば完了

## ヒント
- `int` で表せる最大値は？（`<limits.h>` の `INT_MAX` を表示してみよう）
- 12! と 13! はそれぞれ `INT_MAX` より大きい？小さい？
- 型を変えたら `printf` の書式指定子も変える必要がある
