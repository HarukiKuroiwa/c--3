# 01 配列の最大値

## このプログラムがやりたいこと
2つの配列 `a`, `b` それぞれの最大値を表示する。

## 期待される出力
```
max(a) = 42
max(b) = -3
```

## 症状
`make run` で実行すると、期待と違う値が表示される（どんな値になるかは実行環境ごとに変わる）。

## 課題
1. `make run` で症状を確認する
2. 原因を特定して `problem.c` を修正する（原因は1つとは限らない）
3. `make check` が **PASS** になれば完了

## ヒント
- コンパイル時の警告をよく読もう
- ループの中で `i` と `arr[i]` がどう変わるか、`gdb` や `printf` で確かめよう
- 配列 `b` は全部負の数。その場しのぎの直し方だと `b` で失敗する
