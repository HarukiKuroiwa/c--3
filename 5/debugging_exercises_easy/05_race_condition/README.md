# 05 2つのスレッドでカウント

## このプログラムがやりたいこと
2つのスレッドがそれぞれ共有変数 `counter` を 100万回ずつ増やし、合計 200万を表示する。

## 期待される出力
```
counter = 2000000 (expected 2000000)
```

## 症状
`make run` を何回か実行すると、毎回 200万より少ない、実行ごとに違う値が表示される。

## 課題
1. `make run` を5回ほど実行し、値が毎回変わることを確認する
2. 値が減る理由を「`counter++` が機械語でどう実行されるか」から説明できるようにする
3. `problem.c` を修正し、`make check` が **PASS** になれば完了（5回実行して5回とも一致が条件）

## ヒント
- `counter++` は1つの命令に見えるが、実際は「読む → 1足す → 書き戻す」
- pthread には同時に1つのスレッドしか入れない区間を作る仕組みがある
- この問題の Makefile は最適化を切っている（`-O0`）。最適化するとバグが見えなくなることがあるため
- `make check` ではスレッド用のサニタイザ（`-fsanitize=thread`）も使う
