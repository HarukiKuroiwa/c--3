# set2 連結リストの一括削除

## このプログラムがやりたいこと
連結リストから、指定した値を持つノードを**すべて**削除する（`remove_all`）。3つのリストで試す。

## 期待される出力
```
before: 1 -> 2 -> 3 -> 2 -> 4 -> NULL
remove 2: 1 -> 3 -> 4 -> NULL
before: 5 -> 7 -> 7 -> 8 -> NULL
remove 7: 5 -> 8 -> NULL
before: 9 -> 9 -> 1 -> NULL
remove 9: 1 -> NULL
```

## 症状
最初のテスト（1 2 3 2 4 から 2 を削除）は正しく動く。2つ目以降のテストで、おかしな値が表示されたり、
`Segmentation fault` などで異常終了したりする（どうなるかは環境によって違う）。

## 課題
1. `make run` で、どのテストまで正しく動くかを確認する
2. 正しく動くテストと動かないテストで、**削除するノードの並び方** にどんな違いがあるかを考える
3. 原因を特定して `problem.c` を修正し、`make check` が **PASS** になれば完了

## ヒント
- 異常終了した場所に原因があるとは限らない。`gdb`（Mac は `lldb`）の `bt` で落ちた場所を見たうえで、
  「そこで読んだメモリは、いつ・どこで壊れたのか」をさかのぼろう
- サニタイザ付きで実行すると、「解放済みのメモリに触った場所」と「そのメモリを解放した場所」の両方が表示される
  ```
  cc -g -fsanitize=address problem.c && ./a.out
  ```
- `remove_all` の中で、`prev` は常に「リストに残っているノード」を指しているだろうか
