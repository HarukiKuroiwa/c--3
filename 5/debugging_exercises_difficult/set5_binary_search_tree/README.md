# set5 二分探索木の削除

## このプログラムがやりたいこと
二分探索木（BST）に8個の値を入れたあと、20、60、50 を順に削除する。
削除のたびに、中間順（小さい順）に並べた値と、BST の条件（左 < 親 < 右）を守っているかを表示する。

## 期待される出力
```
start       : 20 30 40 50 60 65 70 80 | BST: OK
delete 20   : 30 40 50 60 65 70 80 | BST: OK
delete 60   : 30 40 50 65 70 80 | BST: OK
delete 50   : 30 40 65 70 80 | BST: OK
```

## 症状
20 と 60 の削除は正しく動く。50 を削除すると、値が重複して `BST: BROKEN` になる。

## 課題
1. 最初の木を紙に描き、20・60・50 がそれぞれ **子をいくつ持つノードか** を確認する
2. 3つの削除が `delete` の中のどの分岐を通るかを、`gdb`（Mac は `lldb`）のブレークポイントや `printf` で確かめる
3. 原因を特定して `problem.c` を修正し、`make check` が **PASS** になれば完了

## ヒント
- 正しく動く削除と、壊れる削除の違いは何か。壊れるときだけ通るコードはどこか
- 子を2つ持つノードを消すとき、「後継で置き換えたあと」に右部分木から消すべきなのは、どの値か
- `delete` の中で `key` はどこでも同じ意味で使われているだろうか
