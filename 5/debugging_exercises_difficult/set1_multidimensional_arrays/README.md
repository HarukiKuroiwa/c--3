# set1 行列の90度回転

## このプログラムがやりたいこと
3×3、2×4、4×2 の3つの行列を、それぞれ時計回りに90度回転して表示する。

## 期待される出力（抜粋。全体は `expected.txt`）
```
original (2x4)
  1  2  3  4
  5  6  7  8
rotated (4x2)
  5  1
  6  2
  7  3
  8  4
```

## 症状
3×3 は正しく回転する。しかし 2×4 と 4×2 では、回転後の行列に `0` が混ざったり、値の並びが崩れたりする。
プログラムは最後まで動いて正常終了する。

## 課題
1. `make run` で、どのテストが正しく、どのテストがおかしいかを確認する
2. 「正しく動くテスト」と「おかしいテスト」の違いは何か、を手がかりに原因を探す
3. `problem.c` を修正し、`make check` が **PASS** になれば完了

## ヒント
- 回転後の行列は何行何列か。`dst` の1行には何個の要素が並ぶか
- 2×4 の場合に `dst` の添字がいくつになるかを、紙に書くか `printf` で表示して確かめよう
- 正常終了していても安心はできない。`make check` のサニタイザが何を検出するかを見てみよう
- **考察**: なぜ 3×3 のテストでは、このバグが見つからないのか
